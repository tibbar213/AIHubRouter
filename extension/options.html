监控列表

默认每 5 分钟检查一次，可自定义间隔和确认轮数。电脑休眠可能延后执行。

为 key 选择模型即开始监控，默认仅预览并使用配置页的默认策略；更换模型会重新开始确认。每个 key 固定一个模型。平台故障转移保持原设置，实际请求仍可能使用其他分组。手动改组将暂停该 key。

连接平台

先在当前浏览器打开 AIHub 并登录，再回来读取配置。连接只在本次浏览器会话内保留。重启浏览器后需重新访问平台。

插件不保存完整 API key；只使用网站登录会话访问 aihub.top。平台页面连接后可以关闭。

新建 Key 的默认策略

添加监控时复制这套策略。在监控卡片里调整各 Key 的策略。

策略规则说明

缺少模型价格的渠道仍可入选。模型价格优先策略在全部合格渠道缺价时按账号倍率选择，同倍率保留当前渠道。设定最高模型价格时，候选必须有可比较的价格。模型价格按每个 Key 的输入:输出比例和缓存命中率混合输入价、缓存价与输出价，再乘账号倍率。最低缓存率可单独设置筛选门槛。参与策略的延迟和成功率必须有指定模型的数据。原始倍率是大厅公布倍率，账号倍率为账号专属倍率；没有专属倍率时两者相同。修改策略后重新开始确认。
